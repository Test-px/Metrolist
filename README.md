## ✨ Features & Highlights

### ⚡ High-Performance Audio & Direct Streaming
- Direct CDN streaming engine with smart queue pre-buffering.
- Dynamic adaptive bitrate and live audio telemetry.
- Audio normalization, equalizer, and crossfade.

### 🎨 Material 3 Expressive UI & Modern Design
- Adaptive ambient theming and Material You dynamic color palettes.
- Fluid AGSL animations, shaders, and expressive motion.

### 🎤 Synchronized Lyrics
- Real-time time-synced lyrics with karaoke highlights and translation.

### 💾 High-Speed Downloader & Metadata
- Parallel chunk downloader with byte-level resumption.
- Embedded ID3/MP4 metadata and synced lyrics for offline playback.
